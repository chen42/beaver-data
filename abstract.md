# Beaver-data: An Agentic Workflow for Reproducible Neuroscience Analysis

Neuroscience studies require repeated decisions about data cleaning, exclusions, model specification, and interpretation. When these decisions remain undocumented, analyses become difficult to reproduce and audit. Beaver-data is an agentic workflow that guides large language models through structured, reproducible analysis of behavioral and biological data.

The workflow organizes projects into standardized directories for raw data, scripts, analysis plans, results, figures, validation, and reports. Before analysis, the agent records study goals, estimands, exclusions, cleaning authority, statistical assumptions, tool preferences, and completion criteria. Raw data remain unchanged, while cleaned datasets and row-level audit records are generated separately. Exploratory analyses use multi-angle diagnostic displays, including distributional, longitudinal, missingness, and model-based assessments. Statistical modeling uses an approved reproducible engine, including R, user-specified software, or Linux analysis tools, with controlled environments and Git-based version tracking. Selected results can undergo independent cross-engine validation through a tool-neutral specification. Timestamped filenames and run logs connect inputs, scripts, model outputs, figures, and decisions across analyses.

Beaver-data is implemented as a reusable, model-agnostic workflow compatible with major large language models and agent platforms that support standard instruction or skill files. It does not replace scientific judgment. Instead, it structures agent behavior so that analytical decisions remain explicit and traceable. This approach provides an auditable path from data intake through reporting and supports reproducible neuroscience research across AI systems and development environments.
